提案：固定报表页（Pinned Dashboard）

不是完整 BI —— 只是把你写好的「SQL + 图表」钉成卡片，下次打开一键全部刷新。

概念一句话：查询工作台里任何一个结果图表，点「钉住」（lucide Pin 图标）→ 它变成下面这个页面里的一张卡片。
  1. 每张卡片 = 一条保存的 SQL + 一个图表配置（复用你已有的保存查询 + ChartSpec，几乎不用新东西）。
  2. 打开页面或点「全部刷新」时逐条重跑 SQL —— 本地文件表、MySQL 联邦表都一样能刷。
  3. 差异化卖点：本地 CSV/Excel 也能进 dashboard，这是在线 BI 做不到的。

实现范围建议：单页、最多 6~8 张卡、无拖拽布局（固定两列）、无定时任务（打开时刷新 + 手动刷新按钮）。 这样后端只需要一张 pinned_cards 表（sql + chart_spec + 标题），前端复用现有图表组件即可，约 2~3 天工作量。
