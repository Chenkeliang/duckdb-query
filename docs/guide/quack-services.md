# Quack 远程服务

此功能自 v2.2.0 起用于桌面版和带 Python 后端的 Web/Docker 部署，浏览器内的 Wasm Demo 不提供此入口。当前使用 DuckDB 2.0.0。

## 添加与浏览

在数据源管理页，或工作台左侧独立的「Quack 服务」分组中，点击「新增服务」，填写服务名称、Quack 地址和服务器提供的 Token。高级设置可配置传输方式、证书指纹和超时。

连接从运行 DuckQuery 后端的机器发起。Docker 部署中的 `localhost` 指容器自身；应填写该容器能够访问的分析服务器地址。

显式点击「测试连接」时，会按需从 DuckDB 官方仓库安装 `httpfs` 和 `quack` 并测试认证。保存配置、启动应用和浏览服务列表不会自动下载扩展。当前离线包未预置 `quack`，受限网络需先安装匹配引擎与平台的官方扩展。Token 在本机按现有连接凭据机制加密保存，接口不返回原值；编辑时留空会保留已保存的 Token。

点击箭头展开服务、库、Schema 或字段列表；点击分支标题本身不会展开或读取结构，与原有连接树一致。展开后可查看远端实际提供的库、Schema、表、视图和字段。目录类型来自服务器，客户端不根据名字推测 MySQL、PostgreSQL 等来源。远端的数据源配置和权限由服务管理员维护；本页不新增或编辑服务器上的 MySQL/PG 连接。搜索栏筛选服务，不会遍历并查询所有远端大表。

## 远程 SQL 标签

选择「新建远程 SQL」会新建一个绑定该服务的独立 SQL 标签。双击表名，或在表的右键菜单选择「打开预览 SQL（100 行）」，会打开该表的预览；若同一服务的相同 SQL 已打开且草稿未改变，则切回已有页。修改过的草稿不会被覆盖，不同服务即使同名也分别保留。聚焦表名后也可按 Enter 或空格打开预览；展开箭头单独控制字段列表。服务右键菜单与其操作菜单提供相同的连接操作。预览入口只填入 SQL，仍需点击「执行」。SQL 标签名称标识服务，查询工具栏和结果标题不再重复展示执行位置或只读说明。原本地 SQL 标签的草稿和执行位置保持独立。

首版只接入 SQL 标签。JOIN、集合、透视和数据探索继续使用原有数据源，远端表不会自动加入这些设计器。远端 SQL 的 AI 问数、错误修复和 SQL 收藏尚未接入；结果区的图表展示、显式重算和下钻保留原服务归属。

本地表和原有数据库连接表也支持双击或右键「打开预览 SQL（100 行）」，只回填编辑器、不自动执行。原有单击选表和右键「预览数据」、导入、删除等操作继续按各数据源的能力提供；历史和收藏的 SQL 预览对话框保持原有行为。

客户端只允许单条可确认的只读语句，并拒绝执行动态 SQL 的函数包装，包括执行序列化 SQL 的 `json_execute_serialized_sql`，避免外层 SELECT 隐藏远端写入。带引号、限定名及 EXPLAIN 内层调用同样检查；同名表别名和 CTE 不受影响。该客户端策略不代表服务器账号已经具备数据库级只读限制；正式服务仍应配置自己的认证和只读授权。

## 结果、取消、导出与保存

- 预览仅在用户未指定最外层 LIMIT/FETCH 时补系统行数上限。
- 取消使用该查询的远端连接 ID，其他查询不受影响。转入后台沿用正在执行的查询，不重放 SQL。
- 刷新、图表重算、导出和下钻使用结果捕获的服务，后续切换编辑器不会改变它们的来源。
- 「保存为表」始终保存到本地 DuckDB。确认弹窗固定打开时的 SQL 和来源；保存过程中出现其他结果不会更换目标。
- 排队保存任务在开始连接前核对受理时的服务配置版本；配置已变化时明确失败，不改投新端点。确认需要使用当前配置后可显式重试，新任务会重新记录当前来源与版本。
- 全量导出或保存遵循弹窗的行数选择；不限制时移除最外层 LIMIT，保留子查询的限制。
- 保存为本地表时使用临时原生 DuckDB 文件传输，不经过 Parquet 或文本转换。原生类型、UNION 的实际成员、VARIANT 中的大整数、间隔微秒及时间的时区偏移都会保留；重名和取消保护继续生效。
- DECIMAL 与大整数在查询结果中保留精度。Parquet 不能无损表示全部 DuckDB 类型：大整数 HUGEINT/UHUGEINT、间隔 INTERVAL、带时区时间 TIME WITH TIME ZONE、VARIANT、枚举 ENUM、位串 BIT、定长数组 ARRAY，以及包含这些类型的嵌套列，会整列导出为文本。文本保留整数位数、间隔微秒和原时区偏移，但原生类型不保留；DECIMAL 的精度与标度、TIMESTAMP_NS 的纳秒则直接保留。
- UNION 及包含 UNION 的嵌套列不支持 Parquet 导出，会明确报错且不生成下载文件。可改用 CSV 文本导出；需要保留 UNION 成员标签和原生类型时，请保存为本地表。CSV 使用 DuckDB 自然文本表示，不承担原生类型往返保证。
- 物化到本地后，从任务列表打开结果会查询该本地表；后台查询快照仍保留其原远端服务。

转入后台时，只有服务端明确拒绝接管，已被替换或关闭的原查询才会被自动取消；网络断开、服务器错误（5xx）、超时或请求中断都不能证明接管失败，任务可能已经在后台运行。未收到确认时，请先查看任务列表核对状态，不要仅因缺少确认就重复执行 SQL；应用也不会自动重放 SQL 或重试接管、取消请求。被取消、被替换或已转入后台的前台执行不写入查询历史，真正的执行错误仍记录为失败。

不提供启动或共享本机 Quack 服务、远端建表改数、上传本地文件到服务或跨服务混合 JOIN。
