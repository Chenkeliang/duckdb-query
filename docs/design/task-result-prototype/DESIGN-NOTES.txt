本次范围
只演示工作台中的执行入口、保存为表、后台任务和结果查看。没有连接数据库，没有修改本次范围之外的正式 React 页面或后端。刷新重置演示数据。

合并方案
执行按钮保留普通预览；下拉中的“保存为表”承接原异步执行和保存到 DuckDB 表。结果区保留同名快捷入口，共用表名、行数范围和来源 SQL 确认窗口。两种来源明确区分：编辑器提交时的 SQL，或当前结果对应的原 SQL。
慢查询的“转到后台”继续同一次查询，不重新运行，不自动保存成表。它与保存为表任务共用右侧任务面板；两种已完成任务均一键查看结果。
保存为表会重新执行选定来源的 SQL，不承诺直接复制已加载的网格数据。完整查询与限行保存继续分别提供，默认完整查询。失败或结果失效后的重新运行创建新执行编号。

草稿和结果
任务入口位于查询标签行右上角，默认收起，点击后从右侧展开。查看结果只替换结果区，不写入编辑器，并自动收起任务面板。关闭按钮及 Escape 也可收起面板，焦点返回入口。创建任务、转后台和完成均不自动展开面板；入口显示运行数，无运行任务时显示任务总数。任务完成只提示，不自动切换结果。查看 SQL 是只读；需要编辑时在新 SQL 标签载入，原草稿保留。“保留查询结果标签”仍是独立开关，默认关闭；从开启切换为关闭时立即只保留当前结果标签。

已实现的原型交互
编辑与新增 SQL 标签、格式化、收藏、历史；前台执行、3 秒后转后台、取消；后台保存、失败与重新运行、结果不可用演示；任务搜索和状态筛选；结果排序、列显示、筛选、框选与复制、图表、全屏、保存、导出；中英文与深浅主题。
CSV、JSON 可下载演示数据。Excel、Parquet 只演示格式选择，未生成文件。SQL 采用固定演示数据与简单模式识别，不是真实 SQL 引擎。数据源连接、AI、JOIN、集合操作、透视、扩展等继续沿用现有产品，此窄范围原型不重新实现这些页面。

建议体验
1. 先改写 SQL 草稿，依次点击右上角任务入口中的两个任务的“查看结果”，确认草稿没有变化。
2. 点击执行右侧下拉 → 保存为表 → 后台保存；继续编辑，等待完成后查看结果。
3. 右上选择“慢查询 / 转后台” → 执行 → 3 秒后转后台；继续编辑，完成后查看结果。
4. 从结果区保存为表，展开来源 SQL，确认使用的是结果原 SQL。
