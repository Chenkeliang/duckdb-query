# DuckQuery v2.2.2 Release Notes

- Fixed long SQL pushing the **Use** button outside the bookmarks drawer. Saved queries can be loaded into the workbench again. [#60](https://github.com/Chenkeliang/duckdb-query/issues/60)
- Added **Copy SQL** to bookmarks. It copies the full statement, including text outside the preview.

The app is **2.2.2**, with DuckDB **2.0.0** and MCP **0.4.1**. The new-database storage format remains `v2.0.0`.
