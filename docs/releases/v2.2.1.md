# DuckQuery v2.2.1 发布说明

## Oracle 数据源

- 桌面版和带 Python 后端的部署可添加 Oracle 只读连接，浏览 Schema、表、视图和字段，并通过 DuckDB SQL 查询、关联及导出。标准包可在「扩展」安装 `oracle_scanner`，离线包已预置该扩展。
- Oracle 账号需要提供 `12C` 密码验证格式。当前驱动无法使用 Oracle 11g 的旧验证格式。[#55](https://github.com/Chenkeliang/duckdb-query/issues/55)
- JOIN 类型冲突的「检查数据」按各侧的数据源和 Schema 查询。两侧共用连接别名时依次检查，并保留基于实际数据的安全转换判断。

## 修复与界面

- 从表右键菜单或查询结果导出的服务端 CSV 带 UTF-8 BOM，方便 Excel 双击打开时识别中文。[#56](https://github.com/Chenkeliang/duckdb-query/issues/56)
- 修正 `FULL JOIN` 中空关联键对应的行来源标记，以及大写 Oracle 对象名的结果列来源显示。
- 欢迎页更新中英文功能说明、运行方式对比和 Docker 启动地址。关联查询的选表提示与工作台操作一致。

## 升级

应用版本为 **2.2.1**，DuckDB 引擎仍为 **2.0.0**，MCP 包仍为 **0.4.1**。新库存储格式为 `v2.0.0`，本版无新增存储迁移。
