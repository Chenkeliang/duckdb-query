# DuckQuery v2.3.0 Release Notes

- Connect to Apache Doris in read-only mode. Browse tables and fields, run native SQL, aggregate charts, drill down, move queries to the background, cancel them, export results, or save them locally.
- Join Doris with local DuckDB, MySQL, PostgreSQL, SQLite, and Oracle. Doris is also available in visual set operations, pivots, and data exploration. Cross-source staging rejects results over 100,000 rows or 64 MiB. Native result staging is limited to 1,000,000 rows and about 256 MiB.
- Native Doris SQL accepts `#` line comments, including after the final semicolon. Chart aggregation uses the Doris dialect for native queries. Background retries preserve the original dialect. Desktop shutdown dispatches remote cancellation independently.

The app version is **2.3.0**, the DuckDB engine is **2.0.0**, and the MCP package is **0.4.1**. New-database storage remains `v2.0.0`.
