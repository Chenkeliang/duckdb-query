# DuckQuery v2.3.0 发布说明

- 新增 Apache Doris 只读连接。可浏览表与字段，执行原生 SQL，进行图表聚合和下钻，或转后台、取消、导出及保存结果。
- Doris 可与本地 DuckDB、MySQL、PostgreSQL、SQLite 和 Oracle 进行跨源关联，也可在可视化工作台使用集合、透视和数据探索。跨源暂存超过 10 万行或 64 MiB 时会报错。原生结果暂存上限为 100 万行及约 256 MiB。
- 原生 Doris SQL 支持 `#` 行注释，包括终止分号后的注释。原生图表按 Doris 方言生成聚合。后台重试保留原执行方言，桌面关停时独立发起远端取消。

应用版本为 **2.3.0**，DuckDB 引擎为 **2.0.0**，MCP 包为 **0.4.1**。新库继续使用 `v2.0.0` 存储格式。
