# DuckQuery v2.2.0 发布说明

本次新增 Quack 远程只读 SQL，补齐各类表的字段展开，更新图表与 AI 推荐交互。保留原有 MySQL / PostgreSQL / SQLite / DuckDB 连接和查询构建器。

## Quack 远程服务

- 数据源管理页和工作台左侧提供独立「Quack 服务」分组；填写已有服务的地址和 Token，浏览实际库、Schema、表、视图及字段类型。CSV / Parquet / DuckDB 等数据由服务器配置并暴露，客户端不上传本地文件或管理服务器上的数据库连接。
- SQL 标签固定绑定所选服务，由远端 DuckDB 执行。客户端验证单条只读 SQL，拦截写操作和动态 SQL 包装；服务仍须配置自己的认证和数据库级只读权限。
- 排队保存的任务记录受理时的服务配置版本；开始连接前若配置已变化，明确失败，不改投新端点。显式重试会重新捕获当前配置。只读校验也覆盖带引号、限定名及 EXPLAIN 中的 `checkpoint`、`force_checkpoint` 和 `write_log` 调用，合法同名别名不受影响。
- 支持查询取消、执行中转后台、结果刷新、图表、导出及保存为本地 DuckDB 表。取消按查询的远端连接 ID 定位；转后台沿用同一次执行，不重放 SQL。结果操作使用执行时捕获的服务，切换编辑器不改变来源。
- 本地保存通过临时原生 DuckDB 文件传输，保留 DECIMAL、大整数、嵌套类型及 UNION 成员标签。Parquet 导出对无法无损表示的类型使用文本列；UNION 或包含 UNION 的嵌套列明确拒绝导出，可使用 CSV 或本地保存。完整类型说明见 [Quack 指南](../guide/quack-services.md)。
- 仅桌面版和带 Python 后端的 Web/Docker 部署支持；Wasm Demo 不支持。首版未接入可视化 JOIN、集合、透视、数据探索、远端 SQL 的 AI 问数/修复或 SQL 收藏，也不提供跨服务混合 JOIN、远端写入或托管 Quack 服务器。
- 显式测试连接会按需安装官方 `httpfs` / `quack`。当前离线包未预置 `quack`，受限网络需预装匹配引擎和平台的官方扩展。连接从后端所在机器发起，Docker 内的 `localhost` 指容器自身。

## 数据源树与 SQL 预览

- 本地 DuckDB 表、原有数据库连接表和 Quack 表均可点击箭头展开字段与类型，按需加载结构；本地与外部表使用独立的轻量元数据请求，不为展开统计全表行数或采样内容。
- 统一树节点字号与字体层级；双击表名或右键「打开预览 SQL（100 行）」只填入 SQL，仍需手动执行。右键显示应用菜单，保留原有数据源支持的预览、导入、结构、导出和删除等操作。
- 重复打开同一服务的相同 Quack SQL 会聚焦已有标签，已修改草稿不覆盖，不同服务不混用；显式新建查询仍打开独立标签。
- 字段缓存按表、连接和 Schema 区分，刷新或编辑连接后更新结构；不覆盖原有 JOIN 等设计器使用的完整元数据缓存。

## 图表与 AI 推荐

- 继续使用现有图表和界面组件，收起低频配置；按实际字段类型与当前结果提供推荐，默认直接绘制当前 SQL 结果，不自动再次汇总或重跑截断查询。
- 分组统计由用户明确选择计算与范围后预览。日期趋势按日期排序，提示重复或无效日期；显示点数限制会提示。默认指标选择避开标识字段；图形坐标近似，提示文本保留后端原始数值精度。
- 当前范围重算保留实际预览行数；移除系统预览上限需显式选择，原始用户 LIMIT/FETCH 和子查询限制继续保留。行尾注释不再破坏聚合或下钻 SQL。
- AI 推荐仅由点击触发，发送当前 SQL、字段、当前结果分布摘要与最多 5 行限量样本到用户配置的模型。建议先显示图型、字段、计算方式和理由，由用户选择预览；过期建议不会覆盖新的结果。

## 版本、升级与验证

应用版本为 **2.2.0**；DuckDB Python/引擎继续为 **2.0.0 / v2.0.0**，MCP 包继续为 **0.4.1**。不发布新的 MCP 包，也不改变 MCP 原有工具或权限模式。Quack 专用工具未加入 Agent/MCP 工具目录。

新库存储继续固定为 `v2.0.0`，不新增存储迁移。数据库、连接和密钥沿用原目录；升级前保留数据及 WAL 备份。保留 v2.1.3 的 Windows 覆盖升级修复。标准包用于应用内自动更新，离线包作为独立下载资产提供。

本次包含只读守卫、同名服务隔离、取消与后台接管、数值/原生类型保存、字段缓存、交互及图表回归。发布流程执行前后端/MCP/Rust 检查、冻结后端冒烟和三平台构建，并在 Windows 验证从已发布旧版覆盖升级及故障安装修复。所有门槛通过后公开安装包。
