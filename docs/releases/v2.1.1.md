# DuckQuery v2.1.1 发布说明

本补丁支持在透视表中不添加分组字段，直接计算整表或筛选后的统计值，并保留 v2.1.0 已发布的工作台和智能体功能。

## 主要更新

- **只选统计字段即可执行。** 行字段和透视列都留空，把字段拖入聚合值，即可使用计数、去重计数、求和、平均值、最小值和最大值，返回一行统计结果。
- **支持多个统计值和筛选。** 可同时统计序列号去重数量与金额合计；筛选先于聚合执行，预览行数上限不会截断参与统计的原始数据。
- **前后端行为一致。** 透视生成与预览接口接受无分组配置，保留类型转换和标识符转义；空表计数为 0，其他聚合按 DuckDB 语义返回 NULL。已有分组透视路径保持不变。

## 使用示例

选择数据表，保持行字段和透视列为空，将“产品序列号”拖入聚合值，选择 `COUNT_DISTINCT` 后执行，即可得到不同序列号的数量。需要金额合计时，可继续加入金额字段并选择 `SUM`。

## 升级说明

- 从 v2.1.0 升级无需新的存储迁移，已有连接、数据和设置保留。
- DuckDB Python 包仍为 `1.6.0.dev379`，引擎仍为 `v2.0.0-alpha39998`，新建数据库存储格式仍为 `v2.0.0`；底层引擎仍为 Preview。本次不升级 DuckDB 引擎，MCP 包保持 `0.4.0`。
- 支持 macOS Apple Silicon、macOS Intel 和 Windows x64，继续提供标准包、离线包和应用内更新。
- 从 1.x 升级前，请备份数据库及 WAL，并阅读 [2.0 大版本说明](https://github.com/Chenkeliang/duckdb-query/blob/v2.0.0/docs/releases/v2.0.0.md)。

## 验证范围

回归测试在项目锁定版本的真实 DuckDB 上执行生成的 SQL，覆盖重复值、NULL、空表、筛选、类型转换、引号字段名及超过一万条输入数据。另通过连接真实后端的 Web 页面完成导入、拖放和执行，核对计数 3、去重计数 2、金额合计 60。发布 CI 运行前后端、MCP、Rust 与远端数据库语义检查，并在三个桌面平台执行冻结后端冒烟测试和安装包构建。
