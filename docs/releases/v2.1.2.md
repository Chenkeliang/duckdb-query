# DuckQuery v2.1.2 发布说明

本次更新升级到 DuckDB 2.0 正式版，新增按表结构配置的数据探索，并优化 MySQL 统计与关联查询的候选下推。扩展页改为紧凑列表，补充 Avro 的官方安装入口。

## 数据探索与 JSON 字段提取

- 选择表后，按实际字段类型推荐计数、去重、求和、均值和时间范围等计算方式；推荐不推断字段的业务含义。执行前可查看 SQL，单行结果可用指标卡片展示。
- JSON 字段发现先应用当前筛选，再采样最多 100 行。更改筛选或字段后会清除旧样本和提取配置，需要重新发现；样本路径不代表完整结构。
- 选择 JSON 路径后可提取为独立列。默认文本提取保留大整数精度；缺失路径或类型转换失败返回 NULL，DOUBLE 仍是近似浮点数。
- 指标基于完整筛选范围计算，采样或结果预览行数限制不会截断参与聚合的输入。

## MySQL 下推与结果一致性

- 可安全转换的时间、整数、DECIMAL、字符串条件先在 MySQL 筛选候选；原始精确过滤和最终关联仍由 DuckDB 执行。
- 条件与计算可等价转换时，单表 COUNT 在源库完成，只传回统计结果；字符串去重计数保留大小写、重音和尾部空格的区别。SUM/AVG 保留在 DuckDB 计算，DECIMAL 经文本恢复精度。
- 数值键与相同 DECIMAL 类型的关联支持候选缩减，包括 JOIN 设计器的列投影。大键集合使用范围筛选，再本地精确关联；保留重复键、NULL 和外连接保留侧。
- 界面区分预计与实际执行方式，数据探索增加取消入口。无法证明安全的条件继续本地执行；本次没有全局开启 DuckDB 原生 remote_pushdown，也不保证所有大表查询都会提速。
- 交叉测试修复 NOT LIKE 与双重否定、重复结果列名、带 REPLACE/RENAME 的星号投影，以及无限日期、零年份、缺失月/日和非法日历日期的边界。

## 扩展页

- 扩展按紧凑行展示，名称、用途、状态和操作保持对齐；SQL 用法按需展开，仍可复制。
- 增加名称/用途搜索、已安装与可安装筛选、无匹配提示及加载失败重试。安装进度和失败后重试继续使用原有接口。
- 新增 Avro 精选目录入口，可安装官方扩展后用 `read_avro(...)` 读取文件；Avro 不是本次新发明的引擎能力，文件导入选择器也没有新增 Avro 格式。

## 引擎与升级

- **应用版本为 2.1.2；DuckDB Python 包为 2.0.0，引擎为 v2.0.0 正式版。** v2.1.1 使用的是 1.6.0.dev379 / v2.0.0-alpha39998。MCP 包保持 0.4.0，浏览器 Wasm 演示使用独立引擎，本次不提供数据探索入口。
- 新数据库继续采用 v2.0.0 存储格式，已有库不会在启动时自动迁移。从 2.1.x 升级无需新增存储迁移；升级前仍应备份 main.db、system.db 和对应 WAL。
- 扩展必须匹配正式引擎及运行平台；标准包包含 Excel，离线包另含 httpfs、MySQL 和 PostgreSQL。Avro 需首次联网安装，安装成功后可离线使用。
- 应用退出前会停止并等待取消监控线程，修复已知的退出引用告警。安装包继续提供 macOS Apple Silicon、macOS Intel 和 Windows x64 的标准包、离线包及应用内更新。
- 从 1.x 升级或需要回退时，请先阅读 [2.0 大版本说明](https://github.com/Chenkeliang/duckdb-query/blob/v2.0.0/docs/releases/v2.0.0.md)。

## 验证范围

回归覆盖真实 DuckDB 执行、MySQL/PostgreSQL 语义矩阵、三种 MySQL 排序规则、数值精度、日期边界、重复键、NULL、外连接、采样与 LIMIT。扩展页验证搜索、状态筛选、用法展开/复制、安装进度与重试，并进行宽屏和窄屏 Web 实测。发布流程在测试和质量检查通过后构建三个平台，并执行各平台冻结后端冒烟检查；全部产物完成后才公开发布。
