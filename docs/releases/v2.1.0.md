# DuckQuery v2.1.0 发布说明

本次更新重做日常查询界面，让接入数据、编写 SQL、等待结果和与智能体协作更连贯。

## 主要更新

- **工作台更清楚。** 重新整理导航、数据源、设置与结果区，统一深浅主题和中英文界面，加入命令面板与常用快捷操作。
- **长查询不中断。** 执行中的只读查询可转到后台继续，无需重新执行；完成后从任务面板恢复结果。修复失败与取消的收尾竞态及请求标记残留。结果列展示可解析的来源，按列名合并时也正确对应原表和字段。
- **SQL 补全更准确。** 按语句位置与输入前缀筛选表、字段和函数，减少无关候选；保留手动补全和完整表名引用。
- **智能体输入更顺手。** 多行输入、中文输入法保护、`@` 选表；解释 / 优化按钮先填草稿。数据源与表范围合并为单行，加号按钮悬停显示提示；修复窄窗切回桌面时的面板停靠问题。
- **AI 修改先看再用。** 返回的 SQL 先展示差异；编辑器内容发生变化时提示冲突。应用修改只更新编辑器，不自动执行。

## 升级说明

从 v2.0.x 升级不新增存储迁移。DuckDB 引擎仍为 `v2.0.0-alpha39998`，Python 包仍为 `1.6.0.dev379`，新建数据库存储格式仍为 `v2.0.0`；本次未切换正式引擎。MCP 保持 `0.4.0`。

从 1.x 升级前，请备份数据库和 WAL，并阅读 [2.0 大版本说明](https://github.com/Chenkeliang/duckdb-query/blob/v2.0.0/docs/releases/v2.0.0.md)。支持 macOS Apple Silicon、macOS Intel 与 Windows x64，继续提供标准包和离线包。

## 验证范围

本地已完成前端、后端、MCP 和 Rust 测试，以及 SQL 补全、AI 面板、列来源与查询取消回归；类型检查、lint、构建和 macOS 实际界面验证通过。发布 CI 另行检查真实 MySQL/PostgreSQL 语义及三个桌面平台构建。Windows 与 Intel Mac 未做本地实机验证。
