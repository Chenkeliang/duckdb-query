# DuckQuery v2.2.1 Release Notes

## Oracle connections

- The desktop app and deployments with a Python backend can connect to Oracle with a read-only account, browse schemas, tables, views, and columns, and query, join, and export data with DuckDB SQL. Install `oracle_scanner` from Extensions in the standard build. The offline installer includes it.
- The driver requires a `12C` password verifier. It cannot authenticate with the older verifier used by Oracle 11g. [#55](https://github.com/Chenkeliang/duckdb-query/issues/55)
- JOIN type inspection checks each column against its own connection and schema. Checks that share a connection alias run in sequence, with conversion recommendations based on the actual values.

## Fixes and interface

- Server-generated CSV files from table and query exports include a UTF-8 BOM so Excel can recognize Chinese text when opening the file directly. [#56](https://github.com/Chenkeliang/duckdb-query/issues/56)
- Fixed row-origin labels for null join keys in full outer joins and column lineage for uppercase Oracle object names.
- Updated the welcome page in Chinese and English with current features, deployment options, and the correct Docker URL. Updated the JOIN table selection hint to match the workspace.

## Upgrading

The app is **2.2.1**, with DuckDB **2.0.0** and MCP **0.4.1**. The new-database storage format is `v2.0.0`. This update introduces no storage migration.
