# DuckQuery v2.1.1 Release Notes

This patch lets the pivot panel compute statistics without grouping fields while retaining the workbench and agent features shipped in v2.1.0.

## Highlights

- **Select metrics and execute.** Leave row fields and pivot columns empty, drag a field into Values, and use COUNT, COUNT DISTINCT, SUM, AVG, MIN or MAX to return one summary row.
- **Combine metrics and filters.** Compute distinct serial numbers and total amounts together. Filters apply before aggregation; the preview row limit does not truncate the source rows included in statistics.
- **Consistent frontend and backend behavior.** The pivot generate and preview endpoints accept configurations without dimensions and preserve casts and identifier quoting. Empty input produces zero for counts and NULL for other aggregates, following DuckDB semantics. Existing grouped pivot paths are unchanged.

## Example

Select a table, leave row fields and pivot columns empty, drag the serial-number field into Values, choose `COUNT_DISTINCT`, and execute. Add an amount field with `SUM` to compute the total in the same result row.

## Upgrade notes

- Upgrading from v2.1.0 requires no new storage migration. Existing connections, data and settings are retained.
- The DuckDB Python package remains `1.6.0.dev379`, the engine remains `v2.0.0-alpha39998`, and the new-database storage format remains `v2.0.0`. The engine is still a Preview; this patch does not upgrade it. The MCP package remains `0.4.0`.
- macOS Apple Silicon, macOS Intel and Windows x64 continue to receive standard installers, offline installers and in-app updates.
- Before upgrading from 1.x, back up database and WAL files and read the [2.0 major-version notes](https://github.com/Chenkeliang/duckdb-query/blob/v2.0.0/docs/releases/v2.0.0_en.md).

## Validation scope

Regressions execute generated SQL on the pinned real DuckDB engine, covering duplicates, NULLs, empty input, filters, casts, quoted column names and more than 10000 input rows. A Web session connected to the real backend also verified import, drag-and-drop configuration and execution: count 3, distinct count 2 and total amount 60. Release CI runs frontend, backend, MCP, Rust and remote database semantic checks, followed by frozen-backend smoke tests and installer builds on all three desktop platforms.
